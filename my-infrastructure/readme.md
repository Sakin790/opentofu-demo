# প্রি-রিকুয়েজিট চেক (Pre-requisites)
1. VM-এ Docker সার্ভিস চালু থাকতে হবে: আপনার রিমোট VM-এ Docker Daemon রানিং থাকতে হবে


2. Deployment

```
cd environments/production
tofu init
tofu apply
```

3. tofu apply দেওয়ার পর টার্মিনালে আপনাকে কনফার্মেশন চাইবে:
```
tofu apply দেওয়ার পর টার্মিনালে আপনাকে কনফার্মেশন চাইবে:


Do you want to perform these actions?
  OpenTofu will perform the actions described above.
  Only 'yes' will be accepted to approve.

  Enter a value: yes
```
